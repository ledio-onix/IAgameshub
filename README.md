# IAgameshub

Bem-vindo ao IAgameshub, um hub de jogos web criados em HTML, CSS e JavaScript. O objetivo do projeto é reunir uma coleção de mini jogos simples, divertidos e fáceis de executar em qualquer navegador.

## 🎮 Jogos disponíveis

- Pong
- Snake
- Breakout

## ✨ Funcionalidades

- Interface moderna e responsiva
- Jogos independentes em pastas separadas
- Fácil execução local
- Estrutura simples para expandir com novos jogos
- Compatível com navegadores modernos

## 🚀 Como executar

### Opção 1: abrir diretamente no navegador

1. Abra o arquivo `index.html` no navegador.
2. Os jogos podem ser acessados dentro de cada pasta respectiva, como `pong/index.html`, `snake/index.html` e `breakout/index.html`.

### Opção 2: usar um servidor local

No terminal, execute:

```bash
python -m http.server 8000
```

Depois abra:

```text
http://localhost:8000
```

## 🕹️ Como jogar

- Acesse a pasta do jogo desejado
- Abra o `index.html` no navegador
- Use os controles indicados em cada jogo
